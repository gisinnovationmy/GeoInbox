Installation

Get GeoInbox running inside QGIS in under 5 minutes.

Installation from QGIS Plugin Repository

Step 1: Open Plugin Manager

In QGIS, go to Plugins → Manage and Install Plugins

Step 2: Search for GeoInbox

In the search box, type "GeoInbox" and press Enter

Step 3: Install Plugin

Click on GeoInbox in the search results, then click Install Plugin

Step 4: Access GeoInbox

After installation, access GeoInbox through Plugins → GeoInbox or look for the GeoInbox toolbar button

System Requirements

QGIS: Version 4.0 - 4.99

First-Time Setup

Configure Settings

After installation, open GeoInbox and go to the Settings tab to configure your download folder and email servers as needed.
