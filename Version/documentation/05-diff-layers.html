Diff layers

After you compare a client layer to a host database, GeoInbox can draw every change as temporary map layers so you can see additions, deletions, and edits before you commit.

Where to find the controls

Open the Versioning tab in GeoInbox. Run Compare, then use Show All Differences to add diff layers to the map. Use Remove Temporary Layers when you are finished reviewing.

Summary diff layers (four main types)

These layers group features by change type. They are added to your QGIS project under names such as [Diff] … (GeoInbox).

ChangeMeaningTypical colour
Features addedIn client, not in hostGreen
Features deletedIn host, missing from clientRed / pink
Attributes changedSame match, different field valuesYellow / cyan tint
Geometry modifiedSame match, different shapePastel orange

Enable Show differences when finished in comparison settings to open these automatically after compare completes.

Detailed geometry overlay (Show All Differences)

Show All Differences builds a fuller picture for matched pairs, including:

  • Client unchanged — context (grey)
  • Attributes changed — attribute-only edits
  • Geometry moved — shape changed (pastel orange)
  • Both changed — geometry and attributes
  • Geom removed parts — portions removed from the old shape (red)
  • Geom added parts — portions added in the new shape (teal)
  • Displacement arrows — line showing movement between old and new position
  • Client added features — new features (bright green)
  • Host deleted features — features only on host (light red)

Layers are memory layers: they do not change your host database until you explicitly commit.

Inspecting a single feature

Host table and attribute diff

In the versioning panel, the host feature table lists match status per row. Select a row to highlight the pair on the map. When attributes differ, GeoInbox can open an Attribute Differences dialog listing field-by-field changes (and schema mismatches if field names or types differ).

Geometry overlay for one pair

For a selected matched pair with geometry changes, GeoInbox can show a temporary overlay of old vs new geometry on the canvas (cleared when you pick another feature or remove temporary layers).

Comparison options that affect diff output

  • Report geometry differences — include shape changes in results.
  • Report attribute differences — include field value changes.
  • Treat empty strings as null — reduces false attribute diffs.
  • Ignored fields — comma-separated list excluded from attribute comparison (e.g. audit timestamps).

See Data versioning for matching rules, commit, backup, and undo.

Cleaning up

Click Remove Temporary Layers to remove GeoInbox diff and overlay layers from the project. This does not undo a commit you already applied to the host — it only clears the visual review layers.
