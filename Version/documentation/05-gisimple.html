Load Files from GISimple

Connect to GISimple server, browse group datasets, and download GIS files for versioning.

🌐 GISimple Integration

GISimple is a geospatial data management platform. GeoInbox integrates with GISimple to allow downloading datasets shared within your organization's groups.

Connecting to GISimple

Step 1: Add GISimple Server

Go to Settings → GISimple Servers and click Add Server. Enter the server URL, Keycloak realm, client ID, and your credentials.

Step 2: Login

Select your GISimple server from the dropdown and click Login. GeoInbox authenticates via Keycloak OpenID Connect.

Step 3: Browse Groups

After successful login, your Keycloak groups will appear. Select a group to view its shared datasets.

Browsing Datasets

Once connected, the GISimple panel shows:

  • Groups List — Your Keycloak groups with access to GISimple datasets
  • Datasets List — Files shared within the selected group
  • File Details — Name, size, upload date, and uploader information

Downloading Files

Step 1: Select Dataset

Click on a dataset in the list to select it.

Step 2: Download

Click Download to save the file to your configured download folder, or Download + Open in QGIS to add the layer immediately.

Step 3: Use for Versioning

Downloaded files can be used as the Client Layer in the Data Versioning tab to compare against your host database.

Supported File Formats

Format Extension Notes
GeoJSON .geojson, .json Recommended for versioning
GeoPackage .gpkg Full support with transactions
Shapefile .shp (in ZIP) Read-only support
KML .kml Basic support

Auto-Trust from GISimple

Users who share files through GISimple groups can be automatically added to your trusted accounts list. This allows their email attachments to be downloaded without confirmation prompts.

To import trusted accounts from GISimple, go to Settings → Trust Settings and click Import from GISimple.

Authentication

GISimple uses Keycloak for authentication. Your credentials are:

  • Stored securely in the QGIS Credential Manager (encrypted)
  • Token-based — Access tokens are refreshed automatically
  • Session-based — You remain logged in until you disconnect or close QGIS
