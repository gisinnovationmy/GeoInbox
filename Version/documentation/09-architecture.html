Local storage

  • config.db — SQLite in the plugin folder: servers, trust lists, cache metadata.
  • Download folder — attachments, GISimple cache, Geov extracts, commit backups (see Settings).
  • QGIS Credential Manager — passwords and tokens, not plain text in project files.

Background work

Network calls (mail, GISimple API, large downloads) run as QgsTask jobs so the QGIS interface does not freeze. Progress and cancel appear in the panel and QGIS task manager.

Two operating modes

GISimple user — authenticate through your GISimple server (Keycloak is handled server-side; the plugin uses issued tokens).

Standalone user — configure IMAP/POP3 directly in Settings without GISimple.
