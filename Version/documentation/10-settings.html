Settings

Configure plugin settings, download folders, and advanced options for optimal GeoInbox performance.

General Settings

Setting Default Description
Download Folder <User Documents>/GeoInbox Directory where email attachments, GISimple files, and Geov imports are saved (required for Geov Format import)
Auto-mark as read Enabled Automatically mark emails as read when attachments are downloaded
Open in QGIS after download Ask Behavior when downloading GIS files: Always, Never, or Ask
Backup before commit Enabled Create automatic backups before modifying host databases

Email Server Configuration

Adding a new server

Click "Add Server" in the Settings → Servers tab to configure a new email connection.

Field Required Description
Server Name Yes Friendly name for this server configuration
Host Yes IMAP/POP3 server hostname (e.g., imap.gmail.com)
Port Yes Server port (993 for IMAP SSL, 995 for POP3 SSL)
Protocol Yes IMAP (recommended) or POP3
Encryption Yes SSL/TLS (recommended), STARTTLS, or None
Username Yes Email account username
Password Yes Stored securely in QGIS Credential Manager

Trust & Security Settings

🔒 Trust All

Download attachments from any sender without confirmation. Use with caution.

📧 Trusted Accounts

Specify individual email addresses that are always trusted.

🌐 Network Trusted (CIDR)

Trust emails from specific IP ranges or domains (e.g., company networks).

🤝 GISimple Auto-trust

Automatically trust group members when using GISimple integration.

⚠️ Security considerations

Always review trust settings carefully. Untrusted attachments could contain malicious data or compromise your GIS projects. When in doubt, manually verify the sender before downloading.

Cache Settings

Setting Default Description
Message cache TTL 24 hours How long to keep email headers in local cache
Max cache size 100 MB Maximum size of the local message cache
Auto-cleanup Enabled Automatically remove old cache entries

Clearing the cache

Click "Clear Cache" to force a fresh fetch of all message headers on next connection. This may take longer but ensures you see the latest emails.

Advanced Options

Setting Default Description
Connection timeout 30 seconds Maximum time to wait for server connections
Max concurrent downloads 3 Number of simultaneous attachment downloads
Debug logging Disabled Enable detailed logging for troubleshooting
Geometry tolerance 0.001 Tolerance for geometry comparison in versioning

Data Storage Locations

# Plugin configuration
<QGIS_PROFILE>/python/plugins/geoinbox/config.db

# Downloaded attachments
<Download Folder>/email_attachments/
  └── <sender>/
      └── <date>_<message_id>/

# GISimple cache
<Download Folder>/gisimple_cache/
  └── <server>/
      └── <group>/

# Backup files
<Download Folder>/backups/
  └── <timestamp>_<operation>.geojson

# Geov Format imports
<Download Folder>/geov/
  └── <project>_<timestamp>/

Resetting Settings

⚠️ Reset to defaults

Click "Reset All Settings" to restore default configuration. This will:

  • Remove all server configurations
  • Clear trust settings
  • Reset download folders
  • Clear message cache

This action cannot be undone. Export your settings first if you want to restore them later.
