Glossary

Key terms and definitions used throughout the GeoInbox documentation.

A - D

Attachment

A file attached to an email message. GeoInbox automatically detects and processes GIS-compatible attachments (GeoJSON, GeoPackage, Shapefile, KML, ZIP archives).

Client Layer

The local QGIS layer representing your field data or working copy. Used as the source for comparison against the host database in versioning operations.

Commit

The process of applying detected changes to the host database. All commits are transactional and include automatic backup creation.

Diff Layer

A temporary QGIS layer that visualizes differences between client and host data. Color-coded to show additions (green), deletions (red), attribute changes (yellow), and geometry modifications (orange).

E - H

Email Browser

The main interface for connecting to mail servers, browsing messages, and downloading GIS attachments. Supports IMAP, POP3, and experimental EWS/Graph protocols.

Feature Matching

The process of identifying corresponding features between client and host datasets. Can be based on ID fields, geometry proximity, or attribute combinations.

Geov Format (.geov)

A ZIP package with project.json and per-layer GeoJSON under layers/. Imported and exported from the GeoInbox Geov Format tab; compatible with MiniGISimple save/load and partial layer import.

GeoPackage (.gpkg)

An open, standards-based, platform-independent, portable, self-describing, compact format for transferring geospatial information. Fully supported by GeoInbox for both reading and writing.

Host Database

The authoritative database (GeoPackage or PostGIS) that serves as the reference for versioning comparisons. Changes are committed back to this database.

I - M

IMAP

Internet Message Access Protocol. The recommended email protocol for GeoInbox as it supports folder browsing, message status tracking, and server-side operations.

GISimple

A web-based platform for geospatial data sharing and collaboration. GeoInbox can integrate with GISimple servers for authentication and data synchronization.

MiniGISimple

A Firefox extension map viewer (MapLibre) that opens and saves .geov projects, supports partial layer import, simple analysis, legend layout, and optional 3D polygon extrusion. Pairs with GeoInbox for desktop ↔ field workflows.

Message Cache

Local SQLite database that stores email headers (From, Subject, Date, attachments) for offline browsing. Configurable TTL and automatic cleanup.

N - S

POP3

Post Office Protocol version 3. A simpler email protocol that downloads messages to the client. Supported by GeoInbox but lacks folder support and advanced features.

PostGIS

A spatial database extension for PostgreSQL. Supported as a host database type for versioning operations with full transaction support.

Sanitization

The process of converting file paths and names to safe, cross-platform formats. Follows GISimple standards: lowercase, spaces to underscores, special characters removed.

Shapefile

A popular geospatial vector data format. GeoInbox can read shapefiles from email attachments and ZIP archives, requiring all component files (.shp, .dbf, .shx, etc.).

T - Z

Trust Rules

Security settings that determine which email senders are automatically trusted for attachment downloads. Can be based on specific addresses, domains, or network ranges.

Undo Stack

A history of reversible operations maintained by GeoInbox. Allows undoing and redoing commit operations with full state restoration.

Versioning

The core GeoInbox feature that compares client datasets against host databases to detect and visualize changes. Supports smart merging and conflict resolution.

ZIP Extraction

Automatic processing of ZIP archive attachments to extract and validate contained GIS files. Supports nested archives and maintains file relationships.

File Format Support

Format Extension Read Write Notes
GeoJSON .geojson, .json ✅ ✅ Native format for backups and exports
GeoPackage .gpkg ✅ ✅ Preferred format for host databases
Shapefile .shp + components ✅ ❌ Read-only, requires complete file set
KML .kml ✅ ❌ Google Earth format, read-only
PostGIS Database ✅ ✅ Full transaction support
Geov Format .geov ✅ ✅ Geov Format tab; extracts under geov/ in Download Folder

Common Error Messages

🔒 "Untrusted sender"

The email sender is not in your trust list. Review and approve manually, or add to trusted accounts.

📁 "No GIS files found"

The email contains no supported GIS attachments. Check file formats and ZIP contents.

🔗 "Connection failed"

Cannot connect to email server. Verify host, port, credentials, and network connectivity.

⚠️ "Matching failed"

Cannot match features between client and host. Check ID fields and matching strategy.
