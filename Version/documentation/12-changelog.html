Changelog

Version history, new features, bug fixes, and development progress for GeoInbox.

Version 0.9.0 (Current) - April 2026

🎉 Initial Release

First public release of GeoInbox with core functionality for email-based GIS data exchange and versioning.

✨ Features

  • Email Browser - Full IMAP/POP3 support with attachment detection
  • Data Versioning - Smart comparison engine for GeoPackage and PostGIS
  • Diff Layers - Visual representation of data changes in QGIS
  • GISimple Integration - Server authentication and data synchronization
  • Geov Format - Import/export MiniGISimple-compatible .geov packages (drop, browse, clipboard paste)
  • Trust System - Configurable security for email attachments
  • Host Connectors - Transactional database operations with backup

📧 Email Features

  • IMAP and POP3 protocol support
  • Secure credential storage in QGIS Credential Manager
  • Automatic GIS attachment detection (GeoJSON, GeoPackage, Shapefile, KML)
  • ZIP archive extraction and processing
  • Message caching for offline browsing
  • Trust-based sender validation

🔄 Versioning Features

  • Smart feature matching (ID, geometry, attributes)
  • Comprehensive change detection (additions, deletions, modifications)
  • Color-coded diff layer visualization
  • Transactional commits with automatic backup
  • Full undo/redo support
  • Conflict resolution strategies

🌐 GISimple Features

  • Keycloak-based authentication
  • Group dataset browsing
  • File upload and download synchronization
  • Auto-trust for group members

🗄️ Database Support

  • GeoPackage read/write with transactions
  • PostGIS full support with schema awareness
  • Shapefile read-only support
  • Automatic GeoJSON backup generation

Documentation updates — September 2026

  • New guide: Geov Format & MiniGISimple (import/export, clipboard paste, round-trip with MiniGISimple 1.0.3).
  • Overview, glossary, settings, and home page updated for .geov workflows.
  • Search index: corrected GISimple integration link to 05-gisimple.html.

System Requirements

QGIS: Version 4.0 - 4.99
